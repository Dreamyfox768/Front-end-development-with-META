Responsive Design: it is to make sure if website visited by smaller screen or different pixel it shows correctly.

RD has 3 practices: flexible grids, ​fluid images and media queries.

-​Firstly, flexible grids are made up of columns, gutters and margins. ​The space between the columns is called the gutter and the spaces between ​the content and the left and right edges of the screen are called margins.  Based on values rather than pixels. 

Next:fluid image by setting the css max-width propery of images to 100%, the images will scale down if so it doesn't over flow. 

Finally, Media query. they allow developers to query the display size, orientation, and aspect ration to conditionally apply css rule. 


responsive grid: fixed grid, fluid grid, and hybrid grid. 
fixed, the grid stay the same.
fluid the grids adapt. 
hybrid can do both.
